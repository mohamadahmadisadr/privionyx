## Token Optimization & Navigation Rules (Graphify)
Always consult the Graphify knowledge graph before running broad grep or file searches to preserve context window tokens:

1. **Check Graph First:** Read `graphify-out/GRAPH_REPORT.md` or parse `graphify-out/graph.json` to inspect component structures, protocols, and view model relationships.
2. **Targeted Reading:** Directly open only the specific `.swift` files identified in the graph paths.
3. **Avoid Broad Searches:** Do not run unconstrained `grep` or file listings across the entire repository.
